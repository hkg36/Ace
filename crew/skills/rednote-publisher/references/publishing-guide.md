# RedNote 发布页指南

发布页入口：<https://creator.rednote.com/publish>

页面文案、字段和布局可能随平台更新而变化。操作时以 Crew 内置浏览器 `browser_use` 返回的当前页面快照为准；以下仅列出常见内容，不代表每个账号或每种笔记类型都会显示全部字段。

## 常见内容

- **封面/素材**：按页面提供的上传或素材选择流程添加用户指定的文件。确认上传字段和文件要求后再操作。
- **标题和正文**：按页面可见的限制填写用户提供或确认的内容。不要假设字符上限。
- **话题**：按页面提供的控件添加用户指定的话题；如果页面要求从候选项中选择，应确认选择结果。
- **发布选项**：根据用户要求设置原创声明、可见范围、定时发布等页面实际提供的选项。未指定的选项保持当前值；不要把某个默认配置当成通用推荐。
- **草稿与发布**：区分保存草稿和公开发布。公开发布前复核内容及选项，并确认用户已明确授权。

## 页面操作与验证

1. 读取当前页面快照，确认目标字段及其当前状态。
2. 使用快照中的 ref 操作；任何会返回新快照的动作后，不复用此前的 ref。
3. 上传文件时使用 `browser-use` 技能提供的 `upload` action，并仅选择用户指定或明确授权使用的文件。
4. 提交后依据页面返回状态确认结果。成功提示、已发布状态或平台确认页可作为验证依据；仅点击按钮或页面短暂无响应不能证明发布成功。
5. 若提交结果不确定，先重新观察页面或状态，不要盲目再次提交，以免重复发布。
